### 01 — Automatisation des tests E2E

Le projet met en œuvre :

- Des tests data-driven.
- Des contrôles statiques et une intégration continue avec GitHub Actions.

**[Consulter le projet sur GitHub →](https://github.com/florent01-star/test-automation)**

### 02 — Conception d'une stratégie de test

**Test Management · Risk-based Testing · Requirements · Traceability**

Construction d'un référentiel de test à partir d'une application e-commerce existante, sans spécifications fonctionnelles initiales.

Le projet comprend :
- Le reverse-engineering fonctionnel et la formalisation de 28 exigences métier et 62 exigences fonctionnelles.
- Une analyse des risques et une approche de test fondée sur les priorités.
- La conception de 63 scénarios de test positifs et négatifs.
- Une matrice de traçabilité reliant 100 % des exigences fonctionnelles à au moins un scénario de test.

**[Accéder au projet complet →](https://florent01-star.github.io/test-strategy/)**
